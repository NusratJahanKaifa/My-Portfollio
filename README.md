# Nusrat Jahan Kaifa — Developer Portfolio Website

A modern, responsive developer portfolio website built with **Next.js**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

This portfolio showcases my skills, projects, education, and developer profile.

---

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern developer-focused UI
- Sticky navigation bar
- Smooth scrolling navigation
- Mobile-friendly navigation menu
- Active section highlighting
- Animated sections and project cards
- Skills categorized by technology type
- Project showcase with GitHub links
- Live demo links for available projects
- Education section
- Contact section
- Social media links
- Resume download option
